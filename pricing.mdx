## Margin math (BN registration)

Against FastCAC's actual flat customer-facing fee of **₦35,000** (as of 2026-07-18, replacing the
old ₦30,000/₦50,000 two-tier model):

| | Amount |
|---|---|
| Customer pays | ₦35,000 |
| VAS cost | −₦27,550 |
| Prembly document verification (means_of_id + passport) | −₦420 |
| **Remaining margin** | **~₦7,030** |

<Warning>
  This is a real, meaningful correction from an earlier version of this page, which used the
  (wrong, sandbox-sourced) ₦17,050 VAS cost and an outdated ₦30,000 customer price, and showed
  ~₦12,530 margin. The actual margin is roughly **40% thinner** than that. See
  `fastcac_api/CONTEXT.md` for the full pricing reconciliation history.
</Warning>
