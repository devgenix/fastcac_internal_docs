All endpoints use base URL `https://vasapp.oasisproducts.ng` (sandbox) or
`https://vasapp.cac.gov.ng` (production) and require the `X_API_KEY` header. Most require a `vrc`
(see [VRC overview](/validation/overview)) rather than a bare `rc_number` — check each endpoint's
request parameters below.

## Documented endpoints (15)

### VRC — Get company

```
POST /api/vas/validation/secure/company
```

<CodeGroup>
```json Request
{ "vrc": "5OBZex7WxA" }
```

```json Response
{
  "statusCode": 200, "status": "OK", "message": "company data",
  "data": {
    "rc_number": "63292863",
    "entity_name": "Holland Vibes homes",
    "entity_type": "INCORPORATED_TRUSTEE",
    "registration_date": "Wed Mar 12 10:10:02 GMT 2025",
    "objectives": ["To provide services to the public", "To deal with General Contractors and merchandise"]
  },
  "success": true, "count": 0
}
```
</CodeGroup>

### VRC — Get company affiliates

```
POST /api/vas/validation/secure/company-affiliates
```

Returns directors/shareholders with per-affiliate detail: name, gender, type, phone, DOB,
nationality, address, and whether they're a corporate affiliate (`is_corporate` + `corporate_name`
+ `rc_number`).

### VRC — Get company share capital

```
POST /api/vas/validation/secure/share-capital
```

Returns `share_capital`, `share_capital_in_words`, `date_of_incorporation`, `company_status`.

### VRC — Get company share distribution

```
POST /api/vas/validation/secure/shares-distribution
```

Returns per-shareholder `shares_allotted` and `share_type` (e.g. `ORDINARY`).

### VRC — Get company assets

```
POST /api/vas/validation/secure/assets
```

Returns registered charges: `type` (`ASSET`), `amount`, `amount_in_words`, `asset` description,
`holding_bank`.

### VRC — Get company certificate

```
POST /api/vas/validation/secure/certificate
```

Returns a binary PDF blob (the certified true certificate as issued by CAC).

### VRC — Get company status report

```
POST /api/vas/validation/secure/status-report
```

Returns a binary PDF blob.

### Get company using TIN

```
POST /api/vas/validation/tin/company
```

<Warning>
  VAS's own example response for this endpoint is copy-pasted from the winding-up endpoint —
  clearly wrong (`"message": "winding up info by company"` with winding-up-shaped data). The
  request shape (`{"tin": "..."}`) and URL are correct; don't trust the example response body.
</Warning>

### Generate TIN

```
POST /api/vas/validation/tin/generate
```

Used when [Get Company TIN](#get-company-tin) returns `null` — no TIN exists yet for the entity.

<CodeGroup>
```json Request
{
  "rc_number": "001", "entity_type": "COMPANY",
  "address": "string", "state": "string", "lga": "string", "phone": "string", "email": "string"
}
```

```json Response
{ "statusCode": 200, "status": "OK", "message": "tin generated successfully", "data": "75494407-0001", "success": true }
```
</CodeGroup>

<Note>
  Only `rc_number` and `entity_type` are required; the rest are optional depending on entity
  details. Worth cross-checking against the "RC = TIN automatically from 2026-01-01" regulatory
  claim elsewhere — this endpoint's existence suggests a TIN record may still need an explicit
  generation step even if RC legally serves as TIN.
</Note>

### Get company TIN {#get-company-tin}

```
POST /api/vas/validation/tin
```

```json Request
{ "rc_number": "35147935", "entity_type": "INCORPORATED_TRUSTEE" }
```

Returns full company data plus a `tin` field — `null` if no TIN has been generated yet (see
[Generate TIN](#generate-tin)).

### Business validation single service (premium)

```
POST /api/vas/validation/single-service
```

Returns everything in one call: entity info, all affiliates (with PSC/shareholder detail), share
details, shareholder allocation. The most expensive single endpoint at ₦7,500 — see
[Pricing](/pricing) — but replaces what would otherwise be several separate calls.

```json Request
{ "rc_number": "18967", "entity_type": "COMPANY" }
```
